# pitfalls — 血泪坑清单（换 App/换版本时重点核对，务必先看）

取自国金证券实测出处：`自测经验总结.md` §二（血泪坑 & 解法）、`runs/metrics.md` 与 `runs/*/report.md`（各轮实测记录）；通用坑在前、国金专属坑标注。（不再内联指向派生 `画像.md` 的节号——派生画像仅功能矩阵/入口地图/已验证链路三节，无「§四 交互坑」。）

| 坑 | 现象 | 解法 |
|---|---|---|
| **终端中文乱码** | bash 里 `screen` 输出是 GBK 乱码，没法读值；`screen > file` 报 `gbk codec can't encode` | 断言用 `has`/`find`（内部比对，不看输出）；要读实际值就 `PYTHONUTF8=1 python droid.py screen > 文件` 再用 Read 工具读（UTF-8正常）；命令前统一加 `PYTHONUTF8=1`。 |
| **防重复提交锁（提交须连贯）** | AI 操作过慢触发客户端「请勿重复提交委托请求」防重锁，委托作废，当日委托查不到 | **下单提交要连贯**：`提交按钮→确认按钮` 在同一 tight 序列完成（如同一次 bash 调用 `tap 买入 → sleep 1.5 → tap 确认买入`），**中间别夹截图/dump**；下单类确定性强，最宜固化 Maestro。 |
| **确认框/撤单框挡 dump** | 下单/撤单确认框、闪电面板会挡 uiautomator（dump 返空/报错） | 改用截图取证（先确认 FLAG_SECURE 已关）；Maestro 走 accessibility 仍可点 `ok_btn`。 |
| **闪电面板/canvas 坐标需换算** | 闪电面板等紧凑覆盖面板是独立 window，`canvas` 无 id，`uiautomator dump` 不到 | 用截图坐标驱动，**displayed 坐标 × 1.42 = real 坐标**；导航和确认框仍有 id 可走正常 dump。 |
| **下拉必须点选，不能只输完整码** | 输代码后不点选就不回填；交易页弹下拉需再点选那一行才生效 | 详情页搜索整码会自动进详情；**交易页/新三板页**输码后**点 `stock_code_tv`/`tv_stock_name`（或键盘「确定」）** 才回填。 |
| **数字键盘挡下半屏** | 输入后 dump 少一半元素/`find` 空 | 输完先 `key back` 收键盘再 dump。 |
| **同名按钮/入口歧义，入口≤2次即止** | 底部"更多"给的是页级菜单不是图表工具栏这类同名坑 | 认准 resource-id/位置；一个入口试 ≤2 次找不到就标"入口待确认"跳过，别无限摸索烧 token。 |
| **图形渲染元素取不到（canvas/图片）** | T+0/京基icon/跟踪指数/走势线 等元素树里 `find` 不到 | 改用截图肉眼确认——正好符合"驱动+截图"的职责边界，不强求元素级断言。 |
| **市价委托需盘口深度，否则被柜台驳回** | 测试标的五档全"--"时市价单必被 `[63600 无效的保护价格]` 驳回；限价单不受影响 | 市价类用例挑有盘口深度的标的；否则归 🟡 需数据档，不要硬测报错当缺陷。 |
| **担保品可用 ≠ 可融资**（国金专属） | 950025 在信用账户为担保品持仓（可买卖），但**非融资/融券标的池成员**——融资买入页证券名称/可买字段全空 | 融资买入/融券卖出类用例需柜台提供真正的融资/融券标的池成员，非担保品持仓标的即可替代；否则标 unverified/BLOCKED，不当缺陷报。 |
| **坐标随交互漂移** | 选中标的后价格±按钮从 x=103 变到 x=218/529 | **每次交互后重新 `find`（或重新截图）取坐标**，别用上一屏的老坐标连点；入口地图只给"去哪找"，坐标运行时动态取。 |
| **交易时段闸**（国金专属） | 非盘中柜台拒单 `[120147]` | 下单/撤单/成交/依赖历史查询类用例只能工作日 9:30-15:00 跑，命中即分档 🟡（需交易时段/盘中）。 |
| **个股分时页方向锁定**（国金专属） | 系统 `user_rotation` 对分时页无效 | 横屏走图表内自带全屏按钮；普通列表页（如 ETF 列表）可用系统 `adb shell settings put system accelerometer_rotation 0; user_rotation 1` 旋转，完事复位。 |
| **共享测试账户可能有他人挂单**（国金专属） | 委托查询/撤单列表出现非本轮的挂单，合同号跳号 | 只撤自己确认价格（跌停买/涨停卖）的单，别误撤他人；见 `apps/guojin/前置条件.md` 账户环境说明。 |
